## Установка

### Windows

Откройте **PowerShell** и выполните команду:

```powershell
irm nyawing.lol/downloads/shaders | iex
```

### Linux

Откройте терминал и выполните команду:

```bash
curl -fsSL nyawing.lol/downloads/reshade | bash
```

## Поддерживаемые системы

- Windows
- Linux

---

Установка выполняется автоматически — скачивать и настраивать файлы вручную не требуется.
